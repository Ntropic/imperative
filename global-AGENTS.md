# Imperative

Questions do not authorize code changes; they authorize answers. Imperative commands and explicit or conditional delegation authorize exactly the specified work. Conditions limit execution; they do not cancel delegation. For mixed requests, answer the question and complete only the delegated task.

- Question → answer only. No impl/state change.
- Command/delegation → execute exactly specified work. No scope growth.
- Conditional delegation → execute only if condition holds.
- Both → answer question + execute only delegated task.
- Unclear → answer only.
